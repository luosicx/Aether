## 💻 macOS 平台工具能力

### 一、系统级控制（完整电脑操控）

macOS 拥有比 iOS 更丰富的系统控制接口，可通过 **MCP（Model Context Protocol）** 服务器实现 AI 对 Mac 的完整操控。

#### 综合方案对比

| 方案 | 工具数量 | 核心能力 | 适用场景 |
|------|---------|---------|---------|
| **MCP macOS Control** | 74 个 | 鼠标/键盘/截屏/OCR/AX树/CoreML/iPhone镜像 | 完整电脑控制 |
| **macOS-MCP** | 丰富 | 文件导航/应用控制/UI交互/浏览器自动化 | 轻量级自动化 |
| **altic-mcp** | 40+ 个 | 消息/日历/文件/窗口/Safari/Chrome/截图 | 日常任务自动化 |

## 📌 整合建议

将上述能力整合到《AI Builder 实战计划》时，建议：

1. **iOS 端优先实现**：系统控制类 + 原生应用类（日历/提醒/相册）+ 视觉感知类，这些是移动端最常用的能力
2. **macOS 端分阶段接入**：先从文件操作 + 浏览器自动化入手，再扩展到完整窗口/应用控制
3. **统一工具协议**：通过 `ToolProtocol`（Day 9）封装两套实现，上层 Agent 完全无感知
4. **权限管理前置**：所有涉及系统权限的工具，在 `ToolRegistry` 注册时预检查，提前引导用户授权
