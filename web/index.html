pub fn cosine(a: &[f32], b: &[f32]) -> f32 {
    let dot: f32 = a.iter().zip(b).map(|(x, y)| x * y).sum();
    let na = a.iter().map(|x| x * x).sum::().sqrt();
    let nb = b.iter().map(|x| x * x).sum::().sqrt();
    dot / (na * nb)
}

细节

细节，决定长期使用。

本地优先、凭据安全、多语言与无障碍，从第一天就写进产品。

本地优先

对话与知识库保存在设备。端侧 MLX 推理在断网时自动接管，不让网络决定能否思考。

凭据安全

密钥与 Token 交给系统保管：Apple 端使用 Keychain，Windows 端使用 DPAPI 加密。

八种语言

简体中文、繁体中文、英语、日语、韩语、法语、德语与西班牙语，可在应用内随时切换。

无障碍

VoiceOver 标签与提示、Dynamic Type 适配，以及关键交互控件的 accessibilityIdentifier。
